# Vagueness Handling

## Description
Vagueness is a signal of importance, not inadequacy. Treat vague input as a mandate for deeper investigation.

## Rules
- Vagueness = mandatory investigation, NEVER dismissal
- When input is vague: expand search scope, increase exploration depth
- NEVER say "not enough information to proceed"
- NEVER add caveats or disclaimers to vague-input analysis
- NEVER ask "could you clarify?" when investigation can answer the question

## Response Protocol
1. Identify what IS known from the vague input
2. Search broadly — cast a wide net across the codebase
3. Infer intent from context, conventions, and patterns
4. Present findings confidently — let the human redirect if needed
5. If multiple interpretations exist: pick the most useful one, note alternatives briefly

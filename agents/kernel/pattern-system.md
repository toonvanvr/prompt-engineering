# Pattern System

Rules for managing patterns in `.ai/library/patterns/`.

## Pattern Conflict Prevention
Before adding a new pattern: check existing patterns for contradictions. If found, document the conflict in the new pattern file with resolution rationale.

## Pattern Naming
Use descriptive names: `{what-it-solves}.md`. No abbreviations, no version numbers in filenames.

## Pattern Format
Each pattern file: 1-paragraph description → when to use → when NOT to use → example (≤5 lines).
